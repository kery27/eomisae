# 라이더 인터뷰 질문지

> 상태: 초안 · 최종 수정 2026-09-28
> 목적: 앱을 만들기 전에 핵심 가설을 확인한다(`기획-검토.md` 8-7, D20).
> 목업: https://claude.ai/artifact/VPKkZEJ3rioXYsU7xBMLnE

## 0. 진행 방법

**대상**
- 지인 라이더 5~10명. 가능하면 **같은 동네**에서 일하는 사람 위주로 모은다(실시간 현황은 같은 동네에서만 의미가 있다).
- 전업과 부업, 배민 위주와 쿠팡이츠 위주가 섞이면 좋다.

**시간과 준비**
- 한 사람당 20~30분. 카페나 대기 장소에서, 일 안 하는 시간에.
- 상대 폰이나 내 폰에 목업 링크를 열어 둔다.
- 녹음하려면 먼저 동의를 받는다. 아니면 메모만.
- 끝나고 커피 한 잔 정도 대접.

**인터뷰 원칙**
1. **아이디어부터 설명하지 않는다.** 1부(지금 어떻게 하는지)를 먼저 묻고, 목업은 2부에서 보여준다. 먼저 설명하면 상대가 맞춰서 대답한다.
2. **"쓸 것 같아요?"보다 "지난번엔 어떻게 했어요?"를 묻는다.** 미래 예측은 대부분 틀리고, 과거 행동은 사실이다.
3. **유도하지 않는다.** "이거 편하죠?" 대신 "이거 보면 뭐가 생각나요?"
4. **"왜요?"를 한 번 더 묻는다.** 첫 대답보다 두 번째 대답이 진짜다.
5. **반박하지 않는다.** 상대가 "이거 필요 없는데요"라고 해도 이유만 묻고 설득하지 않는다. 그게 가장 값진 대답이다.
6. 상대가 말하는 동안 **플랫폼 앱 화면을 찍거나 받지 않는다**(D15).

## 1부. 지금 어떻게 하는지 (목업 보여주기 전, 10분)

**조리 대기 경험**
1. 최근에 가게 도착했는데 음식이 안 나와 있던 적, 마지막으로 언제였어요? 그때 어떻게 했어요?
2. 그럴 때 기다려요, 아니면 취소하고 가요? 뭘 보고 정해요? (몇 분까지 기다리는지, 지원금 때문인지, 콜 상황 때문인지)
3. 기다리는 동안에는 보통 뭐 해요? (유튜브, 웹툰, 게임, 담배, 다른 라이더와 이야기…)
4. 취소하고 떠날 때, 그걸 누구한테 말하거나 어디 적어 둔 적 있어요?

**가게 정보**
5. "이 가게는 맨날 안 나온다" 같은 가게, 몇 군데 알고 있어요? 그걸 어떻게 알게 됐어요?
6. 다른 라이더한테서 그런 정보를 들은 적 있어요? 어디서요? (단톡방, 오픈채팅, 가게 앞에서 직접, 커뮤니티)
7. 그런 가게 콜이 오면 어떻게 해요? 실제로 거절한 적 있어요? 거절 못 하는 이유가 있다면요? (수락률, 콜이 없어서 등)

**콜 받는 순간**
8. 콜이 뜨면 수락할지 정하는 데 몇 초 걸려요? 그때 뭘 봐요?
9. 콜 기다릴 때 폰은 어디에 두고, 어떤 화면을 보고 있어요? (거치대, 주머니, 배달 앱 화면 등)

**신고**
10. 조리 지연으로 제보센터나 고객센터에 신고해 본 적 있어요? 해봤다면 어땠고, 안 해봤다면 왜요?

## 2부. 목업 과제 (10분)

목업을 보여주고 "이런 걸 생각 중인데, 한번 눌러봐 주세요. 생각나는 걸 말로 해주면 좋아요"라고만 한다. **설명하지 말고 지켜본다.** 막히는 곳, 망설이는 곳, 잘못 누르는 곳을 적는다.

| 과제 | 말로 주는 상황 | 볼 것 |
|---|---|---|
| A | "지금 가게 도착했는데 음식이 없어요. 기다릴 거예요." | [대기 시작]을 바로 찾는지, 가게 고르기가 쉬운지 |
| B | "기다리는 동안 유튜브 보러 가 보세요." (데모 [유튜브 보러 가기]) | 떠 있는 타이머를 알아보는지, 거슬려 하는지 |
| C | "음식 나왔어요." | 타이머에서 [픽업]을 바로 누르는지 |
| D | "이번엔 도착했는데 음식이 없어서 그냥 갈 거예요." | [안 나와서 그냥 가요]를 찾는지, 누를 마음이 드는지 |
| E | "콜 기다리는 중이에요." (데모 [배달 앱 보기] → [바삭치킨 콜 흉내]) | 미니 현황을 보는지, 콜을 받을지 말지 무슨 말을 하는지 |
| F | "지금 밀린 가게 목록 한번 보세요." | 숫자를 어떻게 읽는지, 믿는지 |

## 3부. 기능별 질문 (7분)

**기록**
11. 음식이 안 나와 있을 때, 실제로 [대기 시작]을 누를 것 같아요? 안 누를 것 같다면 왜요?
12. [안 나와서 그냥 가요]는요? 떠나는 길에 두 번 누르는 거, 할 것 같아요?
13. 기록하는 게 귀찮을 때가 언제일 것 같아요? (피크, 묶음 배달, 비 오는 날…)

**떠 있는 타이머 · 미니 현황**
14. 유튜브 볼 때 타이머가 떠 있으면 어때요? 어디쯤 있어야 덜 거슬려요?
15. 콜 기다릴 때 미니 현황이 떠 있으면 어때요? 볼 것 같아요, 끌 것 같아요?

**동네 현황 숫자**
16. "바삭치킨 2명 대기 · 18분째"를 보면 그 가게 콜 받아요?
17. **몇 분**이면 거를지 고민해요? 한 명이 기다릴 때와 여러 명이 기다릴 때 달라요? (지금 기준: 1명이면 15분, 2명 이상이면 10분)
18. "30분 안에 3명이 그냥 감"을 보면요? 몇 명쯤이면 확실히 밀렸다고 봐요? (지금 기준: 2명)
19. 이 숫자, 믿을 것 같아요? 안 믿는다면 뭐가 있어야 믿을 것 같아요?

**알림**
20. 대기 알림(15·20·25분)은 쓸 것 같아요? 보통 몇 분에 맞출 것 같아요?

## 4부. 걱정과 신뢰 (3분)

21. 이 앱에 기록하는 거, 걱정되는 게 있어요? (가게가 알까 봐, 플랫폼 약관, 개인정보…)
22. 다른 라이더가 가짜로 기록할 것 같아요? 그렇다면 어떤 식으로요?
23. 이 앱이 배민·쿠팡 앱의 정보(조리 예정 시간 등)를 전혀 안 받는다는 거, 불편해요 아니면 안심돼요?

## 마무리 (2분)

24. 이 중에서 가장 쓸모 있어 보이는 것 하나, 필요 없어 보이는 것 하나만 골라주세요.
25. 같은 동네에서 일하는 라이더 중에 이 이야기 같이 해볼 만한 사람 있어요?
26. 2주 동안 단톡방에서 밀린 가게를 공유해 보는 실험(5부)에 참여할 생각 있어요?

## 5부. 단톡방 수동 실험 (2주)

인터뷰에서 참여하겠다고 한 사람들로 **같은 동네** 단톡방을 만든다. 앱 없이 사람이 직접 공유해 보고, 이 앱이 해결하려는 행동이 실제로 일어나는지 본다.

**공지 (방 만들 때 그대로 올림)**

```
[2주 실험] 밀린 가게 공유방

도착했는데 음식이 안 나와 있으면 이렇게 올려 주세요.
  바삭치킨 ○○점 · 15분째 · 나 포함 2명 대기
  바삭치킨 ○○점 · 안 나와서 그냥 감

지켜 주세요
1. 내가 직접 겪은 것만. 가게 이름 + 몇 분 + 몇 명만 적어요.
2. 욕, 평가("양아치 가게" 등)는 쓰지 않아요.
3. "거르자", "다 같이 받지 말자"는 쓰지 않아요. 판단은 각자.
4. 배민·쿠팡 앱 화면 캡처나 조리 예정 시간은 올리지 않아요.
5. 이 방 내용은 밖으로 퍼 나르지 않아요.
```

규칙 2~5는 기획의 원칙(D1, D4, D15)과 같고, 방이 작고 사실만 공유하면 법적 위험도 낮다(9장).

**운영자가 매일 기록할 것**

| 날짜 | 공유 건수 | 대기 공유 | 그냥 감 공유 | 공유한 사람 수 | 메모 |
|---|---|---|---|---|---|
| | | | | | |

**2주 뒤 참여자에게 물을 것**
1. 공유된 걸 보고 그 가게 콜을 다르게 판단한 적 있어요? 몇 번쯤이요?
2. 공유 안 하고 넘어간 적 있어요? 왜요? (타이핑 귀찮음, 바빠서, 까먹어서…)
3. 공유된 숫자, 믿었어요? 가 보니 달랐던 적 있어요?
4. 앱으로 탭 두 번이면 된다면, 지금보다 더 자주 올릴 것 같아요?
5. 이 방, 계속 있었으면 좋겠어요?

## 판단 기준

| 가설 | 성공으로 보는 기준 (제안) | 근거 |
|---|---|---|
| 공유가 일어난다 | 2주 동안 참여자 **절반 이상**이 **3번 이상** 공유 | 5부 기록표 |
| 공유를 보고 판단한다 (H5) | 참여자 **절반 이상**이 "공유 보고 콜을 다르게 판단한 적 있다" | 5부 질문 1 |
| 바로 떠날 때도 남긴다 (H8) | "그냥 감" 공유가 전체의 **30% 이상** | 5부 기록표 |
| 기록 버튼을 누를 것이다 (H1) | 인터뷰에서 과거 대기 상황을 떠올리며 "그때 눌렀을 것"이라는 답이 절반 이상 | 1부 1~4, 3부 11~12 |
| 표시 기준이 맞다 (D18) | 3부 17~18 답의 중간값이 지금 기준과 ±5분·±1명 이내 | 벗어나면 기준 조정 |

- **모두 넘으면** → 앱 개발(8-7의 순서).
- **공유는 되는데 판단에 안 쓴다면** → 콜 받는 순간에 보이는 방식(미니 현황)을 다시 설계.
- **공유 자체가 안 일어나면** → 왜 안 하는지(귀찮음, 걱정, 필요 없음)를 먼저 확인. 귀찮음이면 앱이 답이 될 수 있고, 필요 없음이면 기획을 다시 본다.

```
이름(별칭):          날짜:
전업/부업:           주 플랫폼:           일하는 동네:

[1부] 대기 때 행동:
      정보 얻는 곳:
      거르는 가게가 있나 / 실제로 거른 적:
      콜 판단 시간·보는 것:
      신고 경험:

[2부] 막힌 과제와 말한 것:

[3부] 대기 시작 누를까:        그냥 가요 누를까:
      타이머·미니 현황 반응:
      거를 기준(분/명):
      숫자 신뢰:

[4부] 걱정:

[마무리] 가장 쓸모 / 필요 없음:
         소개해 줄 사람:          5부 참여:

인상적인 말 그대로:
```
